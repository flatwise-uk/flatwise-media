# flatwise-media

**Public.** Images and documents that Flatwise publishes on social media, hosted here so
the scheduler (Buffer) can fetch them from a public link.

Rules:
- **Only files that are about to be posted publicly.** Nothing internal, no client
  documents, no personal data, no unpublished drafts.
- Layout: `social/<YYYY-MM>/<topic>/<file>`.
- Files are generated by the `social-graphic` skill in the private flatwise-context repo.
  This repo only holds the finished output.
- Don't rename or delete a file once a post that uses it is scheduled: Buffer fetches it
  when the post goes out.
